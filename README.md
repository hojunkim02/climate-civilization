# 기후 시뮬레이션 — 남방진동이 한반도에 미치는 영향

「인공지능및데이터기반과학교육」 교수학습용 시뮬레이션 · 성취기준 [12지구01-02], [12지구01-05]

## 실행 방법

빌드 도구·서버가 필요 없습니다. `index.html`을 브라우저(Chrome/Edge/Firefox)로 열면 바로 실행됩니다.

```
climate-civilization/
├── index.html          # 웹 앱 (이 파일을 브라우저로 열기)
├── core.js              # 시뮬레이션 핵심 로직 (순수 함수, LLM 교체 지점)
├── test/core.test.js    # 로직 자동 테스트 (node test/core.test.js)
└── README.md
```

> 참고: 일부 브라우저는 `file://` 환경에서 localStorage 접근을 제한할 수 있습니다. 그 경우 폴더에서 `python3 -m http.server` 등으로 띄워 `http://localhost:8000`으로 접속하세요. (localhost 접속이며 외부 노출 없음)

## 게임 흐름 (설계서 V. 학생 동작 흐름 기반)

| 단계 | 화면 | 학생이 하는 것 |
|---|---|---|
| 1 | 실제 세계지도 | 탐구 질문 확인, 지도 위 ● 지점을 클릭해 지역 관측 (해수면 온도·대류·기후 상태) |
| 2 | 시작 오버레이 | 시작 지점(A: 칠레 연안 / B: 호주 북동쪽)과 시나리오(엘니뇨/라니냐) 선택 |
| 3 | 관측 데이터 패널 | 대기압·해수면 수온·해수면 높이, 나의 가설 기록 |
| 4 | 화살표 예측 | 8방향 버튼으로 대기 순환 방향 예측 → 시나리오별 정해진 순환 경로와 대조 평가 |
| 5 | 피드백 | 정답이면 이동 + 해당 단계의 대기 순환 원리 설명 / 오답이면 재시도, 2회 연속 실패 시 방향 힌트 |
| 6 | 한반도 도달 | 평년 대비 기압·기온·강수량 영향 분석 모달, 학습지 내보내기 |

## 대기대순환 경로 시스템 (핵심 설계)

남방진동 시나리오마다 **과학적으로 정해진 대기 순환 경로**가 `core.js`의 `ROUTES`에 내장되어 있고, 학생은 지역 관측(지도 ● 클릭)과 관측 데이터를 단서로 그 경로를 찾아냅니다:

- **A(칠레) + 엘니뇨**: 남태평양 → 적도 동태평양(난수, 대류 활발) → 워커 순환 동진 → 아시아 제트 → 티베트 고기압 → 한반도(이상 고온 겨울)
- **A(칠레) + 라니냐**: 무역풍 강화 → 찬 용승류 → 서태평양 웜풀 수렴 → 시베리아 고기압 강화 → 한반도(한파)
- **B(호주) + 엘니뇨**: 웜풀 수축, 인도네시아 대류 약화 → 인도몬순 약화 → 인도차이나 → 아시아 제트 → 한반도
- **B(호주) + 라니냐**: 필리핀해 대류 강화 → 인도차이나 수렴 → 시베리아 고기압 → 한반도

각 이동 단계마다 해당하는 대기 순환 원리(무역풍 약화/강화, 워커 순환, 로스비 파동, 원격 상관 등)가 피드백으로 제공됩니다.

## 지역 관측 기능

지도의 모든 ● 격자 지점(24곳, 실제 경·위도)을 클릭하면 현재 시나리오 상황의 해당 지역 상태를 관측할 수 있습니다:
- 해양 지점: 해수면 온도(평년 대비 편차) + 대류 상태(상승/하강 기류)
- 육지 지점: 원격 상관에 따른 기후 경향 (예: 한반도 — 엘니뇨 시 “이상 고온 경향”)

이 관측 정보가 시나리오의 순환 경로를 추론하는 핵심 단서입니다.

## LLM 교체 방법 (나중 작업)

`core.js`의 `evaluateDir(state, dirKey)`가 방향 판정 지점입니다. 순수 함수로서 `(게임상태, 방향) → {valid, note, hint}` JSON을 반환하므로, 이 함수 내부에서 LLM API를 호출하도록 교체하면 UI 변경 없이 LLM 타당성 평가로 전환됩니다.

## 저장

- 진행 상황은 브라우저 localStorage(`climate-civ-save-v1`)에 자동 저장되어 재접속 시 이어집니다.
- `📄 학습지 내보내기` 버튼: 가설·실패 경험·화살표 경로·예측 관측·한반도 영향 분석이 정리된 Markdown 파일을 다운로드합니다 (설계서 단계 5 토론·발표 자료로 활용).
- `💾 세이브 파일 저장`: JSON 세이브 파일 백업.
