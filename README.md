# 기후 문명 (Climate Civ) — 남방진동이 한반도에 미치는 영향 시뮬레이션

「인공지능및데이터기반과학교육」 교수학습용 시뮬레이션 · 성취기준 [12지구01-02], [12지구01-05]

## 실행 방법

빌드 도구·서버가 필요 없습니다. `index.html`을 브라우저(Chrome/Edge/Firefox)로 열면 바로 실행됩니다.

```
climate-civilization/
├── index.html          # 웹 앱 (이 파일을 브라우저로 열기)
├── core.js              # 시뮬레이션 핵심 로직 (순수 함수, LLM 교체 지점)
├── test/core.test.js    # 로직 자동 테스트 (node test/core.test.js)
└── README.md
```

> 참고: 일부 브라우저는 `file://` 환경에서 localStorage 접근을 제한할 수 있습니다. 그 경우 폴더에서 `python3 -m http.server` 등으로 띄워 `http://localhost:8000`으로 접속하세요. (localhost 접속이며 외부 노출 없음)

## 게임 흐름 (설계서 V. 학생 동작 흐름 기반)

| 단계 | 화면 | 학생이 하는 것 |
|---|---|---|
| 1 | 시작 화면 | 탐구 질문 확인, 시작 지점 선택 (A: 칠레 연안 / B: 오스트레일리아) |
| 2 | 관측 데이터 Form | 현재 지점의 대기압·해수면 수온·해수면 높이, 나의 가설 입력 |
| 3 | 화살표 예측 | 8방향 버튼으로 대기 순환 방향 예측 후 제출 |
| 4 | 피드백 | 타당하면 이동 + 기후 예측 제공 / 틀리면 과학 개념 피드백 (실패 기록 자동 저장) |
| 5 | 지도 | 빨간/파란 원으로 기압 변화 시각화, 이동한 타일은 밝아짐 (안개 효과) |
| 6 | 한반도 도달 | 평년 대비 기압·기온·강수량 영향 분석 + 모달 표시, 학습지 내보내기 |

## 과학 규칙 (core.js `evaluateArrow`)

- **수온 ≥ 28°C + 저기압(≤1008hPa) + 해수면 상승(≥+10cm) → 엘니뇨**: 동쪽(E/NE/SE) 이동 타당
- **수온 ≤ 24°C + 고기압(≥1015hPa) + 해수면 하강(≤-10cm) → 라니냬**: 서쪽(W/NW/SW) 이동 타당
- **중립**: 한국을 향한 북쪽(N/NE/NW) 이동 타당
- 틀린 방향은 기압 경도력·무역풍·워커 순환 개념 기반 피드백을 제공하고 실패 경험으로 기록

## LLM 교체 방법 (나중 작업)

`core.js`의 `evaluateArrow(obs, dirKey)`가 유일한 피드백 생성 지점입니다. 순수 함수로서 `(관측데이터, 방향) → {valid, scenario, feedback{title, body}}` JSON을 반환하므로, 이 함수 내부에서 LLM API를 호출하도록 교체하면 UI 변경 없이 LLM 타당성 평가로 전환됩니다.

## 저장

- 진행 상황은 브라우저 localStorage(`climate-civ-save-v1`)에 자동 저장되어 재접속 시 이어집니다.
- `📄 학습지 내보내기` 버튼: 가설·실패 경험·화살표 경로·예측 관측·한반도 영향 분석이 정리된 Markdown 파일을 다운로드합니다 (설계서 단계 5 토론·발표 자료로 활용).
- `💾 세이브 파일 저장`: JSON 세이브 파일 백업.

## 테스트

```
node test/core.test.js
```

관측 분류, 화살표 타당성 평가, 게임 상태 전이, 한반도 도달 시나리오, 지도 헬퍼 함수를 검증합니다.
